# Kumar Akash — Research Website

Personal research website for Kumar Akash, PhD, focused on human-aware AI,
Human–AI teaming, trust, cognitive modeling, and adaptive intelligent systems.

The site is built as standalone HTML, CSS, and JavaScript and is published
directly with GitHub Pages. Jekyll is not used.

## Local preview

From the repository directory, run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
